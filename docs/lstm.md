# LSTM

## Unconditional

3,662,383 trainable parameters for every length. Vocabulary: A/C/G/T/BOS/EOS/PAD, IDs 0/1/2/3/4/5/6.
Token embedding 128; input LayerNorm, projection to 372, GELU and dropout 0.2; two LSTM layers with hidden width 372; output LayerNorm; one residual MLP block; a 372→744→7 output head.
No class, Tm, null-condition or sequence-length encoder. BOS starts left-to-right decoding.

Fresh seed 42, 50 epochs, effective batch 512, mixed FP16 training; checkpoints selected by full-validation cross-entropy, never test metrics.
The released sampler used temperature 1, no top-k, and lengths sampled from the training empirical distribution. EOS is masked until the requested length and required at that boundary; requested length is a decoding rule, not a neural embedding.
Frozen outputs are provided rather than regenerated by this release builder.

## Tm-conditioned architecture — no released weights yet

3,665,463 trainable parameters. Same backbone and output head.
Train-standardized Tm passes through Linear 1→8, SiLU and Linear 8→8. The 8-D vector is concatenated with token embeddings at every position; the input projection receives 136 dimensions.
There is no length embedding or learned null condition in this LSTM. The constructor's stored Tm mean and SD must come from the checkpoint, not from validation/test data.
